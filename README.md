# 요트 다이스

카지노 테이블 분위기의 요트 다이스 연습 게임입니다. 혼자 점수 연습을 하거나 AI 1~3명(쉬움·보통·어려움)과 대결할 수 있습니다.

- 통을 꾹 누르고 있으면 흔들리고, 손을 떼면 주사위가 굴러갑니다.
- 남길 주사위를 누르면 보관함으로 옮겨집니다.
- 힌트를 켜면 어려움 AI가 추천하는 수를 보여 줍니다.
- 휴대폰에서 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있고, 한 번 접속한 뒤에는 오프라인에서도 열립니다.

설치나 서버 없이 정적 파일만으로 동작합니다. GitHub Pages에서 `main` 브랜치의 루트 폴더를 게시하면 됩니다.
